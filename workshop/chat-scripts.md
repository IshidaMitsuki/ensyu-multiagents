# エージェントに送るチャット文例

このファイルは、演習中にCopilot Chatへ送る文面の例です。各ステップで対象エージェントを選び、該当する文面を送ってください。

カスタムエージェントが表示されない場合は、対象の `.agent.md` の本文を貼り付けたあと、この文面を続けて送ります。

## 1. Planner

対象: `.github/agents/01-planner.agent.md`

```text
研究タスクボードに追加する改善案を1つだけ計画してください。

条件:
- 30分演習の中で実装、テスト、レビューまで終えられる大きさにしてください。
- 外部ライブラリやビルドツールは使わないでください。
- 受け入れ条件は、ブラウザ操作で確認できる形で3つ書いてください。
- 必要なら、UI文言やサンプルタスクなど、追加してよいコンテンツの範囲も決めてください。

作業後は `workshop/agent-log.md` にPlannerとして追記してください。
```

## 2. Implementer

対象: `.github/agents/02-implementer.agent.md`

```text
`workshop/agent-log.md` の最新のPlannerセクションを読んで、受け入れ条件を満たすように実装してください。

条件:
- 変更はできるだけ `app/` 以下に限定してください。
- 既存のタスク追加、状態変更、削除、localStorage保存を壊さないでください。
- 受講者が差分を読めるように、小さく実装してください。
- Plannerが許可した範囲を超える改善案は、実装せず「今後の案」としてログに残してください。

実装後は、変更したファイル、実装内容、手動確認した内容を `workshop/agent-log.md` に追記してください。
```

## 3. Tester

対象: `.github/agents/03-tester.agent.md`

```text
最新のImplementerの作業内容を読んで、ブラウザで確認する手動テストケースを作ってください。

条件:
- テストケースは5つにしてください。
- 正常系だけでなく、空文字、長い文字、削除、再読み込み、スマホ幅の確認を含めてください。
- 実際に確認できないものは「未確認」と書いてください。
- 明らかなtypoや小さな表示崩れだけなら修正して構いません。新機能追加はしないでください。

結果を `workshop/agent-log.md` にTesterとして追記してください。
```

## 4. Reviewer

対象: `.github/agents/04-reviewer.agent.md`

```text
Planner、Implementer、Testerのログと現在の差分を読んで、コードレビューしてください。

重点的に見ること:
- Plannerの受け入れ条件を満たしているか
- 既存機能が壊れていないか
- localStorageのデータ互換性に問題がないか
- UI文言や追加コンテンツが増えすぎていないか
- 演習として受講者が理解できる複雑さに収まっているか

指摘は High / Medium / Low の重大度つきで書いてください。
必要なら小さな修正をして構いませんが、新機能追加はしないでください。

結果を `workshop/agent-log.md` にReviewerとして追記してください。
```

## 5. Documenter

対象: `.github/agents/05-documenter.agent.md`

```text
最新の実装、テスト、レビューのログを読んで、ドキュメントに変更内容を簡単にまとめてください。

条件:
- コードは変更しないでください。
- 実装済みの内容と未実装の案を混同しないでください。
- READMEまたはワークシートに、今回追加した機能の確認方法が必要なら追記してください。


更新内容を `workshop/agent-log.md` にDocumenterとして追記してください。
```

## 進行のコツ

- 各エージェントの実行後に、必ず `workshop/agent-log.md` と差分を人間が読みます。
- 期待と違う出力が出た場合は、次のエージェントへ進む前に修正依頼を出します。
- AIの提案をすべて採用する必要はありません。採用しない判断もログに残すと、演習として学びになります。
